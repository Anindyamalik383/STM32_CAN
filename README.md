# STM32_CAN
STM32F411CEU6( Black Pill) with a CAN controller IC integrated, enabling regular CAN communications to be done.
This is done by interfacing, and a  CAN TransReceiver IC, the one used here is ATA6561-GBQW-N (Atmel IC 
PA12 and PA13 are used for interfacing with the CAN Transreceiver IC
